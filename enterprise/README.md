# 經濟棋局

一台電腦上輪流玩的多人財經桌遊。單頁遊玩可直接開啟 [index.html](./index.html)。

## 同一瀏覽器開多個頁籤

在專案根目錄執行 `node serve.mjs`，然後在同一個瀏覽器的各頁籤開啟 **相同網址** `http://127.0.0.1:4173/enterprise/`；也可按頁面右上角的「開啟同步頁籤」。所有頁籤會共用棋盤、回合、事件、玩家財務與總體數據；一個頁籤的操作會自動同步到其他頁籤。每個頁籤仍可停留在不同頁面，或查看不同季數的儀表板。操作前會檢查共同修訂版；瀏覽器支援 Web Locks 時也會序列化寫入，避免舊頁籤覆寫較新的回合。關閉執行 `node serve.mjs` 的終端機即可停止本機服務。

直接以 `file://` 開啟也可遊玩，但不同瀏覽器對本機檔案的儲存隔離方式不一致。要穩定共用對局，請使用上述本機網址。不同瀏覽器設定檔或無痕視窗不共用資料。

## 玩法

1. 選擇 2–8 位玩家與不同的企業角色，設定淨資產目標與季數上限。新對局會自動以開始時的時間戳記產生亂數種子。
2. 玩家輪流啟動兩個數字的拉霸。每個轉輪會停在 0–6，兩數相加為前進格數（0–12 格）；轉輪依序停定後，棋子逐格移動（不論步數，總移動時間約 2.4 秒），走過的格子會留下螢光外框。總和 0 時停留原地，不抽新卡。罷工幽靈每季結算後隨機移動一次；只有正好停在幽靈格才會罷工：該玩家本季收入歸零、支出照付，這回合不能抽卡或經營（P16 勞資談判破裂例外，經過即觸發）。棋盤交替出現全球、個人與產業事件格；停在事件格時，點擊棋盤中央流動的卡背才會抽卡並翻開事件。
3. 翻開事件卡後按「繼續經營」，棋盤中央會改為該企業的經營提示與本季預估。玩家可聘僱或裁員、借款或還款。銀行玩家可認列與收回壞帳。部分個人事件需要先做決定（指定玩家、接受或放棄、付款或拒付）才能經營；持有 AEO 認證時，拉霸停定後可選擇 −1、0 或 +1 格。
4. 全部玩家完成行動後結算一季。事件影響先套用至十家企業，再建立總體經濟快照，最後由 AI 聯準會依 F01–F10 判斷下一季政策。若新一季有政策調整，棋盤中央會顯示跑馬燈快報，直到玩家啟動拉霸。
5. 有玩家破產、達成淨資產目標，或到達季數上限時結束。

全球事件影響所有適用企業，包括沒有玩家選擇的企業；個人事件只影響抽卡玩家；產業事件影響該產業的所有企業。事件可重複抽到並疊加，同一指標的總變動幅度限制於 −60% 至 +100%。玩家面板顯示已計入事件的本季收入、成本、淨利、投資資產，以及每張事件的剩餘季數。

遊戲自動儲存在目前瀏覽器的 `localStorage`。可從頁面頂端匯出 JSON，或匯入先前的存檔。亂數種子由開始時間自動產生，玩家無須設定；存檔會保留種子與對局狀態。

每家企業初始現金 1,200、投資資產基準值 800。預設勝利目標為淨資產 5,500，最多 12 季；這些值可在開局時調整。

## 員工機制

- **產值曲線**：規模 `x = 人數 / 基準人數`，產值係數 `m(x) = 1 + 0.6(x−1) − 0.3(x−1)²`。營收（銀行另含利息收入、投資公司另含投資收益）與原物料、能源成本都乘上 `m(x)`。2 倍基準人數時達到峰值 1.3，超過後下降；裁光員工時只剩 0.1。
- **裁員**：單季最多裁季初人數的 1/3（參考《大量解僱勞工保護法》30–200 人級距）。每裁 1 人立即支付 1 季的人均人力成本作為資遣費。
- **經營預覽**：輸入人數後即時顯示聘僱與裁員各自的資遣費、人力成本、產值與原料變化、每季淨效果、回收季數與士氣衝擊。
- **勞動力池**：勞動力初始 1,000 人、每季成長 2%，只能從失業人口中聘僱。薪資係數 `1 + 0.03 × max(0, 5 − 失業率%)`，失業率越低人力越貴。
- **士氣**：0–100，初始 100。兩季累計裁員超過 20% 時 −30，單季裁滿 1/3 再 −10；沒有裁員的季度 +10。產值再乘上 `0.8 + 0.2 × 士氣/100`；季末士氣低於 50 時，3% 員工自願離職。

## 景氣連動與平衡

- **景氣連動**：上一季結算的總體數值影響本季營收。汽車、電子、物流隨營收成長率；零售隨失業率反向；能源隨能源價格、農業隨原物料價格、投資公司與科技隨股市（這三項比較的是「上一季相對前 4 季平均」）。利率每偏離 4% 一個百分點，銀行利息收入與借款企業的利息支出各變動 20%。玩家卡上的「景氣 ×1.05」就是本季倍率。
- **事件上限**：每季最多一張全球事件、每個產業最多一張產業事件；之後停到同類格改抽個人事件，避免人數越多事件越密集。
- **非玩家企業**：每季依基準人數比例吸收新增勞動力，失業率不會在無人操作時一路上升。
- **基準收入校準**：`node simulate.mjs [局數] [每局人數]` 會讓電腦依最佳策略（最佳人數、事件選擇、AEO 避開幽靈）自動對戰並統計勝率。各企業的基準收入就是用它在 2、4、6、8 人局反覆校準出來的。

## 個人事件 P07–P16

| ID | 名稱 | 效果 |
|---|---|---|
| P07 | 簽訂團體協約 | 下一次撞到罷工幽靈時照常營運、繼續前進 |
| P08 | 取得 AEO 優質企業認證 | 接下來 2 次拉霸停定後可選 −1／0／+1 格 |
| P09 | 簽訂期貨避險合約 | 付 100；4 季內能源與原物料不受事件影響 |
| P10 | 策略聯盟 | 指定一位玩家，雙方營收 +15%，3 季 |
| P11 | 辦理現金增資 | 可接受：現金 +500；4 季內正淨利的 25% 分給新股東 |
| P12 | 售後租回 | 可接受：投資資產按目前價值換現金；4 季內固定營運成本 +10% |
| P13 | 遭勒索軟體攻擊 | 付 300，或拒付並在下一回合停擺 |
| P14 | 搶下對手大客戶 | 指定一位客群重疊的玩家，2 季內取得對方營收的 10%（消費者市場：零售、汽車、電子、農業、房地產；企業客戶：電子、科技、物流、能源；金融客戶：銀行、投資） |
| P15 | 產品召回 | 立即付 350；營收 −20%，2 季 |
| P16 | 勞資談判破裂 | 罷工幽靈移到前方 1–3 格並停留到你下一次拉霸，這次經過即觸發 |

P09 不會抽給科技、銀行、投資公司；P12 不會抽給投資公司；P15 只會抽給汽車、電子、零售、農業。

## 開發

- `data.js`：規格中的十種企業、十張全球事件卡、十條聯準會規則、擴充的個人與產業卡，以及員工機制參數 `STAFF` 與特殊事件參數 `SPECIAL`。
- `engine.js`：兩輪拉霸、AEO 步數調整、回合、事件與特殊事件選擇、員工產值與士氣、現金流、資產、總體快照與政策引擎。
- `app.js`、`styles.css`、`index.html`：介面。
- `game.js`：供直接開啟 HTML 使用的合併腳本，由 `node build.mjs` 產生。
- `sync.js`：跨頁籤對局修訂版排序與同步判斷。
- `serve.mjs`（專案根目錄）：僅監聽本機 `127.0.0.1:4173` 的靜態檔案服務，同時提供兩種模式。
- `engine.test.js`：規則與回合測試。執行 `node --test`。

修改來源檔後，執行 `node build.mjs` 更新 `game.js`。

本遊戲的數字依據提供的 MVP 規格，僅供遊戲使用。借款增加現金及負債，存量風險會進入總體儀表板；額外借款尚未單獨產生每季利息，企業利息仍依角色基準與聯準會政策計算。
